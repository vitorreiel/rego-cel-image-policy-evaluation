# Compatibilidade entre políticas Rego e CEL para validar imagens Kubernetes

Este conjunto documenta os desfechos agregados da comparação de políticas de validação de imagens. As contagens foram extraídas dos resumos preservados da avaliação.

- `decisoes-agregadas.json` reúne as contagens por contexto de avaliação.
- `adaptacao-e-transferencia.json` reúne as contagens da avaliação de adaptação e transferência.
- `reserva-e-contraste-focal.json` reúne as contagens da reserva histórica e do contraste entre revisões.

Os números dizem respeito aos objetos avaliados fora de um fluxo de admissão Kubernetes. A unidade de contagem é a decisão registrada no contexto indicado, e uma mesma entrada pode integrar mais de um contexto.
